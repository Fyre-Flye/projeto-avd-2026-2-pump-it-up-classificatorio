# src/parte_comum

O enunciado permite fazer a Parte Comum em **notebook Jupyter** ou em scripts `.py` (`eda.py`, `kmeans.py`, `metricas.py`).

O grupo optou pelos **notebooks**, que estão em [`notebooks/parte_comum/`](../../notebooks/parte_comum/):
- `eda.ipynb`: EDA do Wine Quality (4 pilares)
- `kmeans_metricas.ipynb`: padronização, K-Means em duas passadas, matriz de confusão e métricas

Esta pasta é mantida porque faz parte da estrutura obrigatória.
